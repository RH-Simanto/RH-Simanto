## ◈ 01 — ABOUT THE ENGINEER

Hello! I'm **Ratul Hossain**, a Computer Science & Technology student with a strong interest in computer networking and IT infrastructure.

I'm passionate about understanding how digital communication works, how network devices interact, and how reliable, scalable, and secure networks are designed.

My technical interests include:

- Designing and understanding network topologies.
- Configuring routers, switches, and network services.
- IPv4/IPv6 addressing and subnet calculations.
- Routing protocols and switching technologies.
- Network monitoring, diagnostics, and troubleshooting.
- Cybersecurity and infrastructure protection.

## ◈ 04 — ENGINEERING LAB & PROJECTS

### 01. Network Design & Simulation

- Build LAN and WAN network topologies.
- Design network infrastructure using Cisco Packet Tracer.
- Configure routers and switches.
- Develop structured IP addressing plans.

### 02. IP Addressing & Subnetting

- Calculate Network ID and Broadcast ID.
- Determine usable host ranges.
- Perform CIDR and VLSM calculations.
- Design efficient subnet allocation.

### 03. Routing & Switching Lab

- Configure static routing.
- Practice RIP and OSPF.
- Create VLANs and configure trunk ports.
- Implement inter-VLAN communication.

### 04. Network Security Lab

- Understand ACL configuration.
- Study firewall fundamentals.
- Explore VPN technologies.
- Analyze network traffic and security concepts.

### 05. Network Troubleshooting Lab

- Diagnose connectivity problems.
- Use Ping and Traceroute.
- Investigate DNS and DHCP issues.
- Inspect packets using Wireshark.
